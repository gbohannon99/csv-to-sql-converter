📊 CSV to SQL Converter

Upload your CSV file and get instant SQL statements

📖 How to Use ▼
  1. Upload your CSV file - Make sure it has column headers in the first row
  2. Choose your database - Select PostgreSQL, MySQL, SQL Server, SQLite, or Oracle
  3. Review validation results - We'll check for data quality issues
  4. Adjust column types - Override any auto-detected types if needed
  5. Generate SQL - Click confirm to create your SQL statements
  6. Copy or download - Use the SQL in your database!
🔍 What We Validate:
  • Duplicate Headers - Flags columns with the same name
  • Column Consistency - All rows have the same number of columns
  • Whitespace Detection - Flags leading/trailing spaces on values
  • NULL Analysis - Counts missing/empty values per column
  • Boolean Consistency - Detects mixed true/false, 0/1, Y/N representations
  • Mixed Date Formats - Catches YYYY-MM-DD vs DD/MM/YYYY in the same column
  • Invalid Dates - Flags unparseable date values
  • String Length - Warns if values exceed the detected VARCHAR size
  • Primary Key Uniqueness - Flags duplicate values in ID/key columns
  • Problem Row Report - Highlights rows most likely to break your INSERT
  • Schema Validation - Upload a JSON schema to validate types, nullability, max lengths, and numeric ranges
📋 Schema JSON Format:
  • Create a .json file with your table's expected structure
  • Supported constraints: type, nullable, maxLength, min, max, primaryKey
{"table":"customers","columns":[
  {"name":"id","type":"INTEGER","nullable":false,"primaryKey":true},
  {"name":"email","type":"VARCHAR","maxLength":100,"nullable":false},
  {"name":"balance","type":"DECIMAL","min":0,"max":999999}
]}
💡 Pro Tips:
  • ZIP codes? Change from INTEGER to VARCHAR to keep leading zeros
  • Boolean values? Override INTEGER to BOOLEAN for better performance
  • Large text? Use TEXT instead of VARCHAR for unlimited length
